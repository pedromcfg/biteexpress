⚠️ Problemas de Conexão?

Se a app não receber notificações, o Firewall do Windows pode estar a bloquear.

Solução rápida:
  1. Execute open-firewall.bat como Administrador
  2. Ou abra manualmente o Firewall do Windows e permita a porta 3000
